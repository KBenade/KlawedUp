## Project Overview

KlawedUp is a multi-page e-commerce website designed for a handmade press-on nail brand. The website allows users to browse a product catalogue, view detailed product information, filter items based on selected criteria, and complete a simulated checkout process.

The system simulates an online shopping experience using front-end technologies (HTML, CSS, and JavaScript). Product data is passed between pages using URL parameters and dynamically displayed using JavaScript.

The website is designed to demonstrate usability, responsive layout design, and basic e-commerce functionality.


## Website Goals and Objectives

- Develop a functional and visually structured online product catalogue  
- Simulate a basic e-commerce workflow using front-end technologies  
- Implement dynamic product selection and checkout logic  
- Improve user experience through filtering and product browsing features  
- Ensure responsive design across desktop and mobile devices  
- Apply SEO best practices for discoverability  


## Key Features and Functionality

- Product catalogue with multiple nail sets  
- Filtering system for categories, size, style, and design details  
- Image gallery with lightbox functionality  
- Product detail pages with selectable options  
- Checkout system using URL parameters  
- Order summary and confirmation page  
- Responsive layout using CSS Grid and media queries  
- JavaScript-based DOM manipulation for dynamic content updates
